# soul-interview-claude-md

## R — Reading（原文）
> 「将你自己夹载到这个第二大脑文件中。你只需要说：你现在正在搭建我的第二大脑，请一次次提一个问题，深度采访我，最后帮我生成一个CLADMD文件。当这场灵魂采访结束，Cloud就彻底接管了你的整个人生视角、项目和习惯。」（视频 00:01:25-00:01:40；CLADMD 为 CLAUDE.md 口误）

## I — Interpretation（自述）
空的第二大脑只是仓库，填进「你这个人」才变聪明。做法是：在关联好文件夹的 Claude Project 里，让 Claude 一次只问一个问题、连续深度采访你（目标、价值观、项目、习惯、恐惧……），直到覆盖足够维度，最后产出一份 CLAUDE.md——这份文件就是「你」的压缩包，以后每次会话 Claude 先读它，等于带着你的视角开工。这是 Karpathy 方法区别于普通笔记法的关键一步。

## A1 — Application Example（合成演练）
设计演练（非作者亲历）：在「我的第二大脑」Project 里发指令「你正在帮我搭建第二大脑，请一次问一个问题深度采访我，约 15 轮后生成 CLAUDE.md」。Claude 依次问：你过去一年最重要的三个项目是什么？你做决策时最怕什么？你每天固定坚持的习惯？…… 采访结束生成 CLAUDE.md，内含「用户画像 / 项目背景 / 沟通偏好」。下次新会话，Claude 读它即可跳过自我介绍。

## A2 — Future Trigger（关键）
用户会在这些情境下遇到：
1. 想让 Claude 真正「懂我」、记住我的偏好与背景；
2. 问「CLAUDE.md 怎么生成」「怎么让 AI 深度采访我」；
3. 搭好存储后不知道怎么把「自己」装进去。
语言信号：「让AI懂我」「CLAUDE.md」「深度采访」「把我的习惯写进AI」「第二大脑怎么填内容」。
和 setup-obsidian-claude 不同：那个是搭物理结构，本能力是往结构里装入「人」。

## E — Execution（可执行步骤）
1. 确认已搭好 Obsidian+Claude 链接（见 setup-obsidian-claude）→ 完成标准：Claude 能读文件夹。
2. 在 Project 里发采访指令，要求「一次一问、深度、末了生成 CLAUDE.md」→ 完成标准：采访进行中。
3. 逐题回答，覆盖身份/目标/项目/习惯/偏好/边界 → 完成标准：≥10 轮且用户认可覆盖度。
4. 收到 CLAUDE.md 后放入「第二大脑」根目录 → 完成标准：文件落盘且 Claude 能引用。
输入契约：需用户愿意回答私人问题；涉及高度隐私时可只采访非敏感维度。

## B — Boundary（边界）
- 不适用于纯技术 Claude 配置（如 API、提示词模板）。
- 用户不愿透露个人信息时，不逼问；可先生成「最小版」CLAUDE.md。
- 作者盲点：采访质量取决于用户诚实度；敷衍回答会得到敷衍的脑。
